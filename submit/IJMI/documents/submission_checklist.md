# IJMI Submission Checklist

This checklist follows the current Elsevier/International Journal of Medical Informatics submission expectations. Confirm the current official requirements at the journal home page and Editorial Manager immediately before submission.

## Manuscript and front matter

- [ ] Title page with full author names, affiliations and corresponding-author details
- [ ] ORCID iDs for all authors
- [ ] Running title
- [ ] Highlights: 3-5 bullet points, each approximately 85 characters
- [ ] Structured abstract within the journal’s word limit
- [ ] 3-6 keywords
- [ ] Main text in Word (.docx), double-spaced where required by journal/Elsevier template
- [ ] Tables and figures cited in numerical order
- [ ] Figure/table captions fully self-explanatory
- [ ] References formatted consistently and complete (author, year, journal/book, volume/issue, pages or article number, DOI)

## Required declarations

- [ ] Ethics approval/waiver statement
- [ ] Competing interests statement
- [ ] Funding statement
- [ ] Data availability statement
- [ ] CRediT author contributions
- [ ] Declaration of generative AI and AI-assisted technologies (if used)
- [ ] Acknowledgements
- [ ] Registration/protocol information or explicit statement that the study was not registered

## Supplementary materials

- [ ] Cover letter
- [ ] Graphical abstract
- [ ] TRIPOD+AI checklist
- [ ] PROBAST assessment
- [ ] Statistical analysis plan (SAP V1.3) and version history
- [ ] Deviation log
- [ ] Data lock and reproducibility manifest
- [ ] Saliency review template (planned cardiologist review)
- [ ] Analysis source code and software environment (submitted separately or linked)

## Scientific/reporting checks

- [ ] Main conclusion matches abstract, title and Results
- [ ] Primary comparison explicitly reported as estimation due to failed power gate
- [ ] M1+ clearly described as a strong clinical benchmark, not a point-of-care model
- [ ] ECG availability bias reported and discussed
- [ ] Temporal validation clearly separated from external validation
- [ ] Limitations explicitly discussed
- [ ] All 46 references re-verified immediately before submission
- [ ] No fabricated references, DOIs, author names or journal metadata
- [ ] Figures reviewed at final resolution; all fonts and labels legible
- [ ] Tables checked against source `results/*.csv`

## Portal-specific items

- [ ] Upload through Editorial Manager: [Editorial Manager IJMI](https://www.editorialmanager.com/IJMEDI)
- [ ] Cover letter uploaded
- [ ] Manuscript uploaded as Word file
- [ ] Figures uploaded as individual files if required
- [ ] Supplementary files uploaded separately
- [ ] Suggested reviewers entered if requested (3-5, optional)
- [ ] No patient-identifiable information in uploaded files
- [ ] Confirm manuscript is not under consideration elsewhere

---

*This checklist is a submission aid; the official journal guide and Editorial Manager instructions take precedence.*
