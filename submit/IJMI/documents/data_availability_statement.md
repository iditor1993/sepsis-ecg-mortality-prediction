# Data Availability Statement

The data used in this study are publicly available under credentialed or open access as follows:

- MIMIC-IV v3.1: PhysioNet, [https://physionet.org/content/mimiciv/3.1/](https://physionet.org/content/mimiciv/3.1/); DOI: [10.13026/kpb9-mt58](https://doi.org/10.13026/kpb9-mt58)
- MIMIC-IV-ECG v1.0: PhysioNet, [https://physionet.org/content/mimic-iv-ecg/1.0/](https://physionet.org/content/mimic-iv-ecg/1.0/); DOI: [10.13026/4nqg-sb35](https://doi.org/10.13026/4nqg-sb35)

Access to MIMIC-IV requires completion of the PhysioNet data use agreement and CITI training where required by the current PhysioNet policy. The MIMIC-IV-ECG v1.0 release is an open-access dataset record.

The de-identified feature matrices, data-lock hashes and analysis outputs are documented in the project repository. No patient-identifiable information is included in the submission package. The analysis source code and software lock file are provided in `code/` within the submission package and in the repository.
